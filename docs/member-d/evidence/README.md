# Member D Evidence — Database & Query API

Local, reproducible evidence for the Member D database and query layer. Every
screenshot was captured from a real local run of the query service
(FastAPI + SQLite), generated by `generate_local_evidence.py`.

## Structure

| Path | Purpose |
|------|---------|
| `screenshots/` | 14 browser captures — the evidence itself |
| `html/` | Detailed HTML evidence pages (command / request / response / assertions) |
| `generate_local_evidence.py` | Reproduces the HTML pages + manifest from real pytest and FastAPI TestClient output |
| `manifest.json` | Machine-readable index of the generated evidence (paths relative to this directory) |
| `artifacts/` | Regenerated at runtime (SQLite DB + pytest temp); git-ignored |

## Reproduce

```bash
cd docs/member-d/evidence
python generate_local_evidence.py   # regenerates html/, manifest.json, artifacts/
```

Then open each `html/NN.html` in a browser and capture the screenshots.

The script runs the real `backend/lambdas/query` test suite (147 tests) and
issues real FastAPI TestClient requests against a SQLite backend — no cloud
resources are required.
